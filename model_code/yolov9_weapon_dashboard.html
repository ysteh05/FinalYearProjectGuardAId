数据来源与样本用途

Dangerous Items
原五类 YOLO 数据；只保留所选类别框和空标签
按原有 train / val / test 划分
ShanghaiTech negative
上海 Tech 正常场景抽帧；作为背景负样本
原视频级 train / val / test，视频不跨组
Knife Dataset
Knife 标注正样本与空标签负样本
按正／负标签分层切分 70 / 15 / 15
SOHAS Weapon Detection
保留 Knife 正样本；无 Knife 标注的图片为空标签
trainval 按视频帧序列分组，1/8 做 val；原 test 保留
Long Gun Dataset
长枪标注图片；仅在模型类别含 long_gun 时提供正样本
平面数据按正／负标签分层切分 70 / 15 / 15
SOHAS按序列整体切分；同视频帧不会跨 train / val
上海 Tech沿用视频级切分，审计跨组情况
Knife / Long Gun辅助平面集正负分层 70 / 15 / 15
重复图片跨来源去重并优先留在 test，再 val、train
模型类别：Knife · 正样本：Dangerous Items、Knife Dataset、SOHAS · 负样本：所选数据源中的空标签
